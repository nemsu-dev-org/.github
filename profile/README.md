## How to join:
Open an issue on this repo with your name and GitHub link. I will check it and send the invite. Once you accept, welcome to the group.

```bash
$ ./join-nemsu-devs.sh

[1/4] Opening an issue.............. done
[2/4] Submitting name + GitHub link.. done
[3/4] Waiting for review............ pending
[4/4] Invite accepted............... done

> Welcome to NEMSU Devs 404. No refunds, only commits.
```
